# 作品集与箱庭交互验收

## 内容来源

- PMU-Graph：[公开仓库与 README](https://github.com/HEEERE/PMU-Graph)。过程记忆、双图谱、验证与激活门控。
- LLM4EKG：[公开仓库与 README](https://github.com/HEEERE/LLM4EKG)。规则结构化、混合抽取、实体对齐、本体锚定与图谱构建。
- MAJD-Guard：用户指定本地项目的 README、actions/gateway.py、provenance、verification 和 state 模块。只整理机制，不复制运行数据、私有研究文件或凭据。

页面展示工程实现和设计流程，不加入具体实验数据。演示完全在浏览器内使用固定样例，不连接研究后端，也不暗示真实运行结果。技术报告由同一份内容数据生成，避免页面和下载版本不一致。

## 箱庭中的验收路径

1. 首屏点击「记忆档案室」「应急指挥室」或「防御实验室」进入对应项目。
2. 点击模型上的三个编号标记，检查高亮装置、传递信号、场景字幕和右侧步骤同步。
3. 切换演示分支，检查结果明确变化：记忆验证通过/失败、引用证据完整/缺失、污染路径/干净路径。
4. 点击场景下方「下一步」和「重看」，检查可完整走完且循环回到起点。
5. 从顶部「技术报告」进入阅读区，展开设计、取舍和验证章节；下载 Markdown。
6. PMU / EKG 的源码入口指向各自仓库；每个项目都有带项目主题的邮件入口。
7. 按 Tab 检查焦点留在详情层，Esc 关闭；左右箭头保留场景切换。
8. 在手机和静态版重复流程；无 WebGL 时保留步骤、分支、报告与联系操作。

## 视觉与性能

- 保留程序化微缩模型与原有描边；木质底台、喷漆设备、墙面、地砖及湿路面有不同表面响应。
- 保留单主阴影光源，区分冷色环境光、侧后轮廓光与暖色实际灯具；卡片和低性能设备沿用画质降级。
- 详情场景按左侧真实可用宽度取景，避免模型被信息面板遮住。
- 场景字幕与交互步骤共用状态。防御平台线缆信号随步骤移动，污染与干净路径使用不同颜色。
- 自动动画遵循现有降级策略；新增信号和高亮动画遵循减少动态效果偏好。
- 七张静态场景海报及分享封面需随材质、灯光、文字更新重新生成。

## 命令

```sh
npm run dev
npm run qa:portfolio  # 内容、热点、分支、下载、焦点、移动端、静态回退
npm run qa -- http://127.0.0.1:5173/ # 原有场景导航与切换回归
npm run posters       # 更新七张静态海报
npm run og            # 更新分享封面
npm test
npm run lint
npm run build         # 生成报告、类型检查、生产构建
```

浏览器脚本使用已安装的 Chrome。验收截图在 `tmp/portfolio-qa/`，不进入网站发布目录。
