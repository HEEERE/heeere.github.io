# 雨夜箱庭体验

这轮改版保留作品集的信息与原有私人庭院入口，补齐开场、环境声音、场景交互和阅读细节。声音全部由浏览器本地合成，不下载远程音频，也不需要第三方播放器。

## 访问行为

- 首次桌面访问：约 1.8 秒的窗光与箱庭轮廓开场，最终落向首页便利店。点击、滚动、触摸或键盘输入都能结束，遮罩不截获输入。
- 回访与手机：简化淡入。减少动态效果、直接进入场景、静态版与海报导出不播放完整片头。
- 3D 加载：保留静态海报，角落灯点表示准备状态。加载完成后灯点淡去；下载或渲染失败保留静态展示与正文。
- 声音：导航和展览内均有设置。默认关闭，环境音、音乐及音量分别控制；记住用户选择，但跨页面重载仍等待用户手势启动音频。
- 环境音随房间渐变，背景页淡出。进入场景与切换演示步骤有轻微反馈，悬停没有音效。
- 到访状态仅保存在当前浏览器会话中。返回顶部不重播片头，不清除声音设置或到访记录。

## 场景细节

| 场景 | 细节与触发方式 |
| --- | --- |
| 雨夜便利店 | 自动门、雨纹、局部反光；偶尔出现的室内剪影；门旁显示访客本地时间；与网站一致的箱庭海报。 |
| 记忆档案室 | 收集步骤：纸卡落入托盘；验证步骤：工作台灯加强；通过后激活：文件柜亮起稳定状态灯。失败分支不会亮起复用灯。 |
| 应急指挥室 | 桌面证据与图谱节点共同高亮；关系随步骤逐段出现，失败分支采用暖色提示。 |
| 防御实验室 | 路径跟随步骤推进；危险动作抵达时关闭闸门；干净分支恢复通道并显示低饱和绿色。 |
| 学习工作台 | 保留光标和热气，书签靠近时轻抬，书脊印有研究主题。 |
| 工具工坊 | 右侧技能组支持悬停、点击与键盘聚焦，对应工具或机柜获得轮廓与标签。 |
| 街角邮箱 | 接近联系入口或邮箱时灯光变暖、投递口轻抬。邮件入口是 mailto 链接，不宣称邮件已经送达。 |

研究场景底座侧面刻有项目名与研究编号。场景编号继续沿用原有 01–07 顺序；主展排序不改变场景间前后导航顺序。

## 阅读与导航

当前章节显示细线标记；场景卡片始终提供进入提示。关闭展览后返回入口焦点并短暂描边，原阅读位置保留。实现细节使用原生 details，展开时先显分隔线，再显示正文。报告保留原生下载链接，并短暂显示“已开始下载”。

联系区以“雨还在下，欢迎留一封信。”与暖灯邮箱收束。已有品牌入口的长按与键盘 garden 手势保持原实现。

## 代码与验证

- `src/experience/`：声音偏好校验、音频合成与跨场景状态。
- `src/ui/Opening.tsx`、`SoundControls.tsx`、`ReportDownload.tsx`：开场和控件。
- `src/three/LivingDetails.tsx`：钟表、海报、剪影、纸卡、证据路径、书签与工具提示。
- `src/styles/experience.css`：开场、灯点、过渡、设置面板和移动端样式。
- `scripts/experience-qa.mjs`：浏览器端检查真实音频信号、独立静音、背景淡出、开场跳过、设置持久化、焦点恢复、下载、技能联动和手机布局，保存截图与声音样本。

本地验证：`npm run build` 后运行 `npm run qa:release`。完整发布流程另执行类型检查、lint、单元测试和依赖审计。体验检查已加入 GitHub Pages 发布门禁。
