# 上线验收 · 2026-10-23

本次目标是将现有作品集准备为可部署的 GitHub Pages 静态站点，并按用户要求发布。发布内容位于 `dist/`；生产发布由 GitHub Actions 完成，最终状态以对应工作流记录为准。

## 修复与优化

- 美术细节：减少雨丝密度与长度，收敛湿路面高光；为木材、喷漆与地砖增加粗糙度变化，区分室内地面与雨夜街道。
- 展陈细节：底座新增内收底脚与下沿，黄铜铭牌增加沉孔螺钉与细拉丝；刷新全部七张场景海报及分享封面。
- 页面细节：统一导航印章、场景编号、卡片角标、项目目录细线与流程控件的视觉层次。

- 静态版与 3D 版改用唯一的状态来源，修复通过 `#/simple` 访问后无法切回 3D 的问题。
- 3D 引擎独立加载，首屏文字与海报不再等待引擎；卡片接近视口才加载模型、创建画布。静态版不请求 Three.js。
- 主入口 JS 由约 269 KB 降为约 62 KB（未压缩，独立入口 chunk；不包含共享 React 与按需 3D 资源）。首页顶部初始只创建一个场景画布。
- 离屏场景与后台标签页暂停持续渲染；减少动态效果偏好可以实时应用，使用按需渲染。
- 场景按钮使用稳定的层级；带流程标记的项目场景停止自动运镜，避免点击目标持续移动。
- 弹窗打开时背景不可交互；Tab / Shift+Tab 保持焦点，关闭回到打开按钮，切换项目重置内容滚动；浏览器前进、后退与直接访问链接均可正常退出。
- 手机菜单支持 Escape、点击外部、焦点离开与桌面尺寸切换时关闭，菜单按钮扩大到 44 × 44 像素。
- 提升辅助文字对比度，预加载首屏海报，补齐 404 返回入口与无 JavaScript 的报告链接。
- 修复 Service Worker 分享 POST 使用相对重定向 URL 的错误；测试在临时浏览器上下文中进行，不触碰个人庭院数据。
- 更新 Vite、Vitest 与存在已知漏洞的构建依赖，保留网站运行依赖及既有庭院 / Android 工作。

## 复现验证

```sh
npm ci
npm run lint
npm test
npm run build
npm audit --audit-level=high
npm run qa:release
```

`qa:release` 自动在 `127.0.0.1:4175` 启动生产预览，依次执行发布、作品集和导航验收，退出时关闭服务器。需要该端口空闲且本机安装 Chrome；CI 使用 `npx playwright-core install --with-deps chromium` 安装锁定版本对应的浏览器。

截图、运行结果保存在 `tmp/release-qa/` 和 `tmp/portfolio-qa/`，不进入发布产物。单元测试覆盖场景映射、庭院加密与研究数据；浏览器测试覆盖实际访问与点击，不以编译成功代替功能验收。

## 发布方式与验证边界

- 沿用 `https://heeere.github.io/` 与根路径部署；生产输出包含首页、庭院入口、静态资源、三份报告和自定义 404。
- Pull Request 和 `main` 推送都会执行类型检查、Lint、单元测试、构建、全量依赖审计与生产浏览器验收；仅 `main` 推送或手动工作流可部署。
- 只有检查成功才上传 Pages 产物；浏览器截图与结果额外保存为 7 天的 Actions artifact。
- 本地验证使用 Chrome / 软件 WebGL，包含 320、390、768、1024 像素视口。没有将其等同于 Safari、Firefox 或实体手机 GPU 的验证。
- GitHub Pages 的线上 HTTP、HTTPS、自定义 404 响应与实际部署状态在 Actions 发布完成后单独检查。
